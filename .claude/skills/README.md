# Skills de diseño

Copiadas de https://github.com/emilkowalski/skills (commit e8a175d, licencia MIT — ver `LICENSE-emilkowalski-skills`).

- **apple-design** — principios de diseño y movimiento fluido de Apple (WWDC) traducidos a la web.
- **mobile-native** — hacer que la PWA se sienta nativa en el móvil (safe areas, 100vh, tap highlight, zoom de inputs…).
- **emil-design-eng** — criterio general de pulido de UI y animación.
- **animate** — construir animaciones con la curva/duración correctas.
- **review-animations** — revisión estricta de animaciones (invocar con `/review-animations`).
